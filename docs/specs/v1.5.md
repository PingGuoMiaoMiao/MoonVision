# MoonVision v1.5 Specification

## Summary

`v1.5` is the finalization line for the current MoonVision competition deliverable. It keeps the core image-processing API stable and focuses on the labeled bacteria-review workflow, reproducible validation commands, and review-ready reporting.

## Scope

- Keep the existing MoonBit-native image-processing modules stable.
- Preserve the three bundled visual demos: object counting, edge detection, and document enhancement.
- Extend the bacteria-review workflow with practical validation controls.
- Report detection results through F1-oriented, recall-oriented, and precision-oriented views.
- Keep generated images, CSV files, and HTML reports out of version control.

## Delivered Capabilities

- `GrayImage` and `RgbImage` containers with pixel access and mutation.
- Grayscale conversion, thresholding, Otsu thresholding, adaptive thresholding, invert, brightness, and contrast operations.
- Box blur, Gaussian blur, sharpen, and median blur.
- Sobel, gradient magnitude, binary edge extraction, and Canny.
- Binary erosion, dilation, opening, and closing.
- Connected components, bounding boxes, contours, contour hierarchy, contour approximation, convex hulls, rotated rectangles, and shape descriptors.
- PNG byte export, SVG overlays, and HTML reports.
- Bacteria-review batch script with `SampleFolders`, `MaxImages`, `ExcludeRenameCopies`, `ForceRerun`, per-preset scores, best-alignment overlays, label summaries, size summaries, and mode summaries.

## Validation

Core checks:

```powershell
moon check
moon test
```

Bundled demo checks:

```powershell
moon run src/demo/object_counting
moon run src/demo/edge_detection
moon run src/demo/document_enhancement
```

Fast bacteria-review check:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run_labeled_bacteria_review.ps1 -SampleFolders 346 -ExcludeRenameCopies
```

Full local labeled review:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run_labeled_bacteria_review.ps1 -ForceRerun
```

## Non-Goals

- No OpenCV binding.
- No GUI.
- No video processing.
- No DNN or machine-learning model integration.
- No Python or WASM wrapper.
- No commitment to include local generated review output in the repository.

## Risks

- The bacteria-review metrics depend on the local annotated dataset selected by the script's `InputRoot` parameter.
- Recall-oriented bacteria routes intentionally expose high-recall results even when false positives are high.
- Full labeled review can be slow because it runs the native probe across all matching annotated images.
